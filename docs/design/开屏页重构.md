## 1. 网格系统 (Grid System)

开屏页基于 **10 行 × 5 列** 的等分视口网格进行布局定位。

| 维度 | 分段数 | 单格尺寸 |
|------|--------|---------|
| 水平（列） | 5 | `20vw` |
| 垂直（行） | 10 | `10vh` |

**坐标记法约定**：
- 列编号从左至右，记为第 1 列 ～ 第 5 列；列 N 的水平范围为 `[(N-1) × 20vw, N × 20vw]`。
- 行编号从上至下，记为第 1 行 ～ 第 10 行；行 M 的垂直范围为 `[(M-1) × 10vh, M × 10vh]`。
- "第 M 行底部边界"即 `M × 10vh`（例如第 4 行底部 = `40vh`，第 7 行底部 = `70vh`）。

## 2. 背景色块 (Background Color Block)

### 2.1 基础属性

- **颜色**: `#c23643`（Primary）
- **层级**: 背景层，位于页面内容之下

### 2.2 几何约束

#### 宽度范围
色块横跨全部 5 列，即从第 1 列左边界延伸至第 5 列右边界，宽度等于视口宽度（`100vw`）。

#### 高度与倾斜底边

色块顶边平齐视口顶部（`top: 0`）。底边**不水平**，而是一条对角线，由以下两个锚点确定：

| 锚点位置 | 坐标 |
|---------|------|
| 左侧锚点 | 第 1 列左边界 × 第 4 行底部 → `(0, 40vh)` |
| 右侧锚点 | 第 5 列右边界 × 第 7 行底部 → `(100vw, 70vh)` |

对角线从左侧 `40vh` 处向右侧 `70vh` 处线性延伸，形成左高右低的斜边（斜率 = `(70 - 40)vh / 100vw`）。

#### 实现参考（CSS clip-path）

```css
/* 四顶点顺序：左上 → 右上 → 右侧锚点（右下） → 左侧锚点（左下） */
clip-path: polygon(
  0 0,
  100% 0,
  100% 70vh,
  0 40vh
);
```

## 5. 图层系统 (Layer System)

开屏页由三个图层叠加构成，从下至上依次为：Base Layer → Top Layer → Mask Layer（遮罩逻辑）。

---

### 5.1 Base Layer（基底视图）

| 属性 | 值 |
|------|----|
| `z-index` | `1` |
| 背景色块颜色 | `#c23643` |
| 全局底色 / Logo 颜色 | `#ece9e4` |

页面的物理实体层，承载所有可交互元素。

---

### 5.2 Top Layer（反相视图）

| 属性 | 值 |
|------|----|
| `z-index` | `2` |
| 背景色块颜色 | `#ece9e4`（与 Base Layer 对调） |
| 全局底色 / Logo 颜色 | `#c23643`（与 Base Layer 对调） |
| `pointer-events` | `none`（禁止事件穿透劫持） |

DOM 结构与 Base Layer **1:1 完全克隆**，所有元素的位置、尺寸、层级关系与 Base Layer 严格一致，仅两种主色互换。Top Layer 本身全幅覆盖视口，其实际可见区域由下方 Mask Layer 的裁切区域决定。

---

### 5.3 Guide Line（引导线）

引导线并非独立的视觉图层，而是 Mask Layer 裁切形状的几何基准线。其参数同时定义了遮罩口的位置与宽度。

| 属性 | 值 |
|------|----|
| 起点 | `(60vw, 0vh)` |
| 终点 | `(calc(20vw - 50px), 100vh)` |
| 线宽 | `100px` |
| 端点形状 | 圆角（`stroke-linecap: round`） |

**几何推导**：
- 起点 `(60vw, 0)` 位于视口顶边，偏右侧。
- 终点 `(20vw - 50px, 100vh)` 位于视口底边，落在第 1 列右边界（`20vw`）向左偏移半线宽（`50px`）处，与下滚页面的丝带中心线对齐。
- 线段方向为右上 → 左下，与背景色块斜底边方向呼应。

**实现细节**：
- 起终点沿线段方向再各向视口外延伸 `60px`（`GUIDE_OVERSHOOT`），让圆角端笔落在 SVG `viewBox` 之外被默认裁掉，避免视口内出现可见拐点。
- 视口内最终观感为一根 `100px` 宽的单段斜带，与下滚页面的 `GuideLine` 自然衔接。

---

### 5.4 Mask Layer（遮罩逻辑层）

Mask Layer 不是一个独立的 DOM 元素，而是作用于 Top Layer 的 **CSS Clip-Path 裁切区域**。

**遮罩规则**：

- 裁切形状为以引导线为中轴、向两侧各扩展半线宽（`50px`）的矩形带。
- Top Layer 中**仅处于遮罩口内的像素**被 GPU 送入帧缓冲区显示；遮罩口之外的 Top Layer 像素完全透明，露出下方 Base Layer。
- 最终视觉效果：观察者看到一条沿引导线走向的"色反条带"——条带内呈 Top Layer 的反相配色，条带外呈 Base Layer 的原始配色。

**实现参考**：

```css
/* 以引导线起终点为基准，向两侧各扩展 50px（半线宽）构建四边形遮罩 */
/* 起点法线方向偏移量 dx, dy 由线段方向向量的垂直分量决定 */
.top-layer {
  clip-path: polygon(
    /* 起点左侧 */  calc(60vw - 50px * sin(θ))  calc(0vh - 50px * cos(θ)),
    /* 起点右侧 */  calc(60vw + 50px * sin(θ))  calc(0vh + 50px * cos(θ)),
    /* 终点右侧 */  calc(20vw - 50px + 50px * sin(θ))  calc(100vh + 50px * cos(θ)),
    /* 终点左侧 */  calc(20vw - 50px - 50px * sin(θ))  calc(100vh - 50px * cos(θ))
  );
}
/* 注：θ 为线段与竖直方向的夹角，由起终点坐标在运行时计算后注入 CSS 变量 */
```

> **动效预留**：遮罩口的实际可见长度（从起点向终点的裁切进度）作为动画驱动变量，初始值为 `0`（Top Layer 完全不可见），动效播放时由 `0` 扩展至完整线段长度，形成"线条由上至下绘制"的视觉效果。具体动效参数在后续动效章节定义。

## 6. 完整图层 z-index 栈

| 图层 | z-index | 说明 |
|------|---------|------|
| Base Layer | `1` | 物理实体层（背景色块、Logo、可交互元素） |
| Top Layer | `2` | 反相克隆层，`pointer-events: none` |
| 信封 | `3` | 位于 Top Layer 之上，独立定位 |
| 全局导航栏 | `4` | 常驻最顶层，跨页面固定 |

> 模态框与全局遮罩层级高于导航栏，此处不列入开屏页栈定义。

## 7. 入场动效 (Intro Animation)

动效由生命周期驱动，页面挂载后自动按序播放。**动效播放完成前，禁止页面下滑**（通过 Lenis `stop()` 与 `intro-scroll-locked` 类共同锁定）；动效结束后恢复正常滚动。

---

### 7.1 阶段一：引导线绘制（Mask Sweep）

**本质**：所有 DOM 节点在三维空间中坐标零位移，真正发生移动的仅为作用于 Top Layer 的 **Alpha 掩码通道（Alpha Mask Channel）** 的裁切进度值。

| 属性 | 值 |
|------|----|
| 时长 | `1000ms` |
| 前置延迟 | `120ms` |
| 运动曲线 | 快进缓出（`cubic-bezier(0.4, 0, 0.2, 1)` 或等效的 `ease-out`） |
| 驱动变量 | 遮罩口沿引导线方向的裁切进度 `progress: 0 → 1` |
| 起始状态 | 遮罩口长度为 `0`，Top Layer 完全不可见 |
| 结束状态 | 遮罩口扩展至完整线段长度，Top Layer 在引导线宽度内完全显现 |

**实现方式**：Top Layer 使用单一内联 `<svg>`，通过 `<mask>` + 带圆角端笔的 `<line>` 构建遮罩口；`<motion.line>` 的 `strokeDashoffset` 由 `length → 0` 驱动绘制进度。原生 `stroke-linecap: round` 直接提供圆角端笔，无需 JS 计算法线。详见 `src/components/shared/EnvelopeIntro.tsx` 中的 `SWEEP_DURATION_MS` / `SWEEP_DELAY_MS` / `guide` 常量。

**运动规则**：

- 遮罩口从引导线**起点** `(60vw, 0)` 向**终点** `(calc(20vw - 50px), 100vh)` 方向单向扩展。
- 扩展过程中，遮罩口已过区域持续保持可见，不收回。
- 整个阶段内，Base Layer 与 Top Layer 的所有 DOM 节点位置严格锁定在屏幕绝对坐标系中，无任何物理位移、缩放或旋转。

---

### 7.2 阶段二：信封飘落（Envelope Drop）

**触发时机**：阶段一 `onAnimationComplete` 触发 `setSweepDone(true)` 后立即启动。

| 属性 | 值 |
|------|----|
| 动效类型 | Spring 弹簧飘落 |
| 起始位置 | 信封中心点在最终落点上方 |
| 落点 | `(80vw, 70vh)`（§4 定义的中心点坐标） |
| Spring 参数 | `stiffness: 30, damping: 12, mass: 1.5` |
| 落定后状态 | 进入轻微呼吸浮动 |

---

### 7.3 滚动锁定策略

- **锁定起点**：页面挂载，动效生命周期启动的同一帧。
- **锁定方式**：
  - `page.tsx` 在 `locked = mounted && !isIntroReady` 时给根容器追加 `intro-scroll-locked` 类。
  - `EnvelopeIntro` 内部在 `phase === 'opening'`（点击蜡封至路由跳转）阶段额外追加同样的锁定类。
  - 桌面端：调用 `lenis.stop()` 禁用 Lenis 平滑滚动。
  - 移动端：`overflow: hidden` 通过上述锁定类统一施加。
- **解锁时机**：阶段二（信封飘落）动效完全结束后，同帧恢复滚动（`setIntroReady(true)` → 移除 `intro-scroll-locked` / `lenis.start()`）。
- **开信链路锁定延续**：`EnvelopeIntro.handleOpen` 从点击蜡封到 `router.push('/map')` 期间，`phase === 'opening'` 继续锁住页面；路由切换完成由 `TransitionOverlay` 接管视觉衔接。

---

### 7.4 无障碍降级（Reduced Motion）

在系统开启 `prefers-reduced-motion: reduce` 时：

- Mask Sweep 瞬时绘满（遮罩口直接跳到完整长度）。
- 信封 Spring 瞬时落定到 `(80vw, 70vh)` 终态。
- `setIntroReady(true)` 立即触发，用户可第一时间点击蜡封进入 `/map`。

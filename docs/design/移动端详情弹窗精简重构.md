## 1. 设计目标

本次迭代覆盖两个关注点：

### 1.1 详情弹窗精简

将 `MobileDetailModal` 从"可导航的多故事阅读器"精简为"单故事沉浸阅读视图"。

- 移除全部 prev/next 导航入口，降低认知负担
- 将角色信息头（头像、角色名、地点/日期标签）与关闭按钮合并到弹窗**顶部固定 header**，不随内容滚动
- 去除图片顶部的渐变遮罩，保持视觉的纯净度
- X 关闭按钮位于顶部 header 右侧，始终可见，为唯一的退出入口

### 1.2 瀑布流体验优化

- **Lenis 平滑滚动**：移动端保留原生 `overflow-y-auto`，不引入 Lenis（见 §6.1）
- **卡片圆角**：`rounded-[8px]`（8px）
- **卡片间距收窄**：列间距 `gap-2`(8px)，卡片下边距 `mb-2`(8px)
- **入场动效重设计**：点击卡片时，详情页从右侧以整页滑入的方式覆盖瀑布流，关闭时向右滑出退场

## 2. 变更清单

### 2.1 移除项

| 元素 | 位置 | 说明 |
|------|------|------|
| 渐变遮罩 `bg-gradient-to-b from-black/20 via-transparent to-transparent` | 图片区域浮层 | 无信息承载，影响图片纯净度 |
| 浮动左右导航箭头容器 `motion.div [absolute inset-x-2 top-1/2]` | 卡片绝对层 | 翻阅逻辑整体移除 |
| 操作提示卡片 `div [flex flex-col gap-2 p-4 bg-stone-50]` | 文本区域底部 | 无导航后提示内容失去意义 |
| 图片区域内的 X 关闭按钮 `button [absolute top-8 right-8]` | 图片浮层 | 迁移至弹窗顶部固定 header 右侧 |

### 2.2 新增 / 调整项

#### 顶部固定 header（弹窗最顶端，不随内容滚动）

头像、角色名、地点标签在同一行水平排列，关闭按钮位于这一行右侧：

```
div  [flex items-center justify-between gap-4 px-6 py-3 border-b border-stone-100 bg-background flex-shrink-0]
├── div  [flex items-center gap-3 min-w-0]    ← 头像(w-10/h-10) + 角色名 + 地点标签（浅色背景+深色文字）
└── button  [w-12 h-12 X 关闭按钮]     ← 图标 strokeWidth=3.5，48px 外堤犰提供隐式点击热区
```

**地点标签样式**：`bg-paper-strong text-ink`（浅色中性色背景 + 深色正文字体颜色），移除原 `bg-stone-900 text-white uppercase tracking-widest`。

**角色名样式**：`<span>` 元素（不继承 h 元素样式），显式指定 `tracking-[0.12em]` 对齐全局 `h2`/`h3` 标题字距规范。

## 3. 实际 DOM 架构

```
motion.div  [fixed inset-0 z-[1200]]
│
├── motion.div  [absolute inset-0 bg-black/60 backdrop-blur-sm]  ← 背景遮罩（opacity 动画，点击关闭）
│
└── motion.div  [fixed inset-0 bg-background flex flex-col]  ← 主内容（x: 100%→0 平移动画）
    │
    ├── header  [flex items-center gap-3 px-4 py-3 border-b flex-shrink-0]  ← 顶部固定 header
    │   ├── motion.div  [size-10 圆形头像]  ← 独立子元素
    │   ├── div  [flex-1 flex items-center gap-2]  ← 角色名(span, tracking-[0.12em]) + 地点标签
    │   └── button  [size-12 X关闭，strokeWidth=3，48px热区]
    │
    └── div  [flex-1 overflow-y-auto scrollbar-hide]  ← 可滚动主体区
        │
        ├── div  [relative w-full]  ← 图片区域（无浮层，无 layoutId）
        │   └── Image (w-full h-auto object-contain)
        │
        └── div  [px-8 pt-8 pb-16 flex flex-col]  ← 正文区域
            ├── motion.div  [class="text-reading text-stone-700"]  ← 内容按 \n\n 分割为 <p> 元素
            └── div  [mt-12 pt-6 border-t ... 署名行]
```

## 5. 调用方影响

`MobileDetailModal` 的父组件（`StoryFeed` 或 `MobileExperience`）需同步移除全部导航相关 prop 传入，接口简化为：

<MobileDetailModal
  story={selectedStory}
  onClose={() => setSelectedStory(null)}
/>

## 6. 瀑布流体验优化（StoryFeed）

### 6.1 滚动方案

**决策**：移动端保留原生 `overflow-y-auto` 滚动，不引入 Lenis。

**原因**：Lenis 的 wrapper/content 容器绑定模式要求将容器设为 `overflow: hidden`，iOS/Android 的触摸事件在该模式下需要 Lenis 全面接管，实测触摸无响应。原生惯性滚动在移动端已足够流畅。

**穿透防护**：`MobileDetailModal` 打开时，`MobileExperience` 将 `document.body.style.overflow = 'hidden'`，关闭后恢复。

### 6.2 卡片圆角

**值**：`rounded-[8px]`（精确 8px）。

### 6.3 卡片间距

**列间距**：`gap-2`（8px）

**卡片下边距**：`mb-2`（8px）

### 6.4 副标题文案

顶部 header 副标题由 `Hainan University` 改为 `HNU-TimeLetter`，去掉 `uppercase` CSS 类，保持原始大小写。

### 6.5 详情页入场动效

点击卡片后，详情页从右侧以整页滑入的方式覆盖瀑布流，关闭时向右滑出退场。与 §3 DOM 架构一致。

### 6.6 正文字体规范

详情页正文使用全局 `.text-reading` 类（定义于 `globals.css`）：

- 字号：`var(--text-base)`
- 行高：`1.5`
- 字重：`300`
- 字距：`0.045em`
- 字体：`ZouLDFXKAJ.ttf`（正文字体）

**段落渲染**：`story.content` 按 `\n\n` 分割为多个 `<p>` 元素，每段 `mb-[1em]`（局陣一倍字号）。段内单行换行用 `whitespace-pre-wrap` 保留。

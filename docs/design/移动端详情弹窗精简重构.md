# 移动端详情弹窗精简重构 + 瀑布流体验优化

> **版本号**: v2.1.0
> **状态**: 待实施
> **适用路由**: `/map`（移动端掌心集邮册）
> **实施文件**:
> - `src/components/mobile/MobileDetailModal.tsx`
> - `src/components/mobile/StoryFeed.tsx`
> - `src/components/mobile/MobileExperience.tsx`

---

## 1. 设计目标

本次迭代覆盖两个关注点：

### 1.1 详情弹窗精简

将 `MobileDetailModal` 从"可导航的多故事阅读器"精简为"单故事沉浸阅读视图"。

- 移除全部 prev/next 导航入口，降低认知负担
- 将角色信息头与关闭控件合并到同一行，形成清晰的阅读头部
- 去除图片顶部的渐变遮罩，保持视觉的纯净度
- 确认右上角 X 为唯一的退出入口

### 1.2 瀑布流体验优化

- **Lenis 平滑滚动**：为瀑布流区域接入 Lenis，与桌面端保持一致的丝滑惯性滚动体验
- **卡片圆角收窄**：将当前圆角缩减为原值的 25%，使卡片更接近硬朗的纸张质感
- **入场动效重设计**：点击卡片时，详情页以"从右侧滑入"的方式覆盖，替代原有的放大展开动效

#### 文本头部容器（替换原 `flex items-center gap-5 mb-8`）

原有的角色头像行和关闭按钮合并为一个 flex 行，作为可滚动内容区的**文本区域顶端**：

```

```

## 6. 瀑布流体验优化（StoryFeed）

### 6.1 Lenis 平滑滚动

**现状**：`StoryFeed` 的滚动容器使用原生 `overflow-y-auto`，无惯性平滑效果。

**方案**：在 `StoryFeed` 内部（或其父容器 `MobileExperience`）为瀑布流区域接入 Lenis，配置与桌面端 `useVirtualScroll` 保持一致。

**实现要点**：

- Lenis 需绑定到具体的 DOM 容器而非 `window`，使用 `wrapper` + `content` 参数指定滚动容器
- 在 `MobileDetailModal` 打开期间（`selectedId !== null`），应暂停 Lenis（`lenis.stop()`），关闭后恢复（`lenis.start()`），避免底层滚动穿透
- Lenis 实例由 `MobileExperience` 创建并持有，通过 `ref` 或 state 传递给需要控制的逻辑

**配置参数**（与桌面端一致）：

```ts
new Lenis({
  wrapper: scrollWrapperRef.current,  // 瀑布流外层容器 div
  content: scrollContentRef.current,  // 内部 columns-2 容器
  duration: 1.2,
  easing: (t) => Math.min(1, 1.001 - Math.pow(2, -10 * t)),
  smoothWheel: true,
  wheelMultiplier: 1,
  touchMultiplier: 2,
})
```

### 6.2 卡片圆角收窄

**现状**：`StoryCard` 使用 `rounded-md`（Tailwind 默认值 `6px`）。

**变更**：缩减为原值的 25%，目标约 `1.5px`，使用 `rounded-[1.5px]` 或 `rounded-sm`（`2px`）实现。

> 注：Tailwind 内置 `rounded-sm = 2px`，`rounded = 4px`，`rounded-md = 6px`。选用 `rounded-sm` 作为最接近目标的内置值，或直接使用 `rounded-[1.5px]` 精确控制。

### 6.3 详情页入场动效重设计

**现状**：`MobileDetailModal` 以底部弹出 + `layoutId` 共享布局的方式展开（卡片膨胀放大效果）。

**变更目标**：点击卡片后，详情页从右侧以整页滑入的方式覆盖瀑布流，关闭时向右滑出退场。

**实现方案**：

- 移除 `MobileDetailModal` 容器上的 `layoutId`（共享布局动效是放大效果的根源），以及 `items-end`（底部弹出定位）
- 容器改为 `fixed inset-0`（全屏覆盖），使用 Framer Motion 的 `x` 属性做平移动画：

```tsx
// 入场：从右侧 100% 滑入
// 退场：向右侧 100% 滑出
<motion.div
  initial={{ x: '100%' }}
  animate={{ x: 0 }}
  exit={{ x: '100%' }}
  transition={{ type: 'spring', stiffness: 300, damping: 30 }}
  className="fixed inset-0 z-[1200] bg-background flex flex-col overflow-hidden"
>
```

- 图片区域的 `layoutId="story-img-{id}"` 同样移除（共享布局在非放大动效下意义不大，且与平移动画并存会产生冲突）
- 背景遮罩层（`bg-black/60 backdrop-blur-sm`）保留，单独用 `opacity` 动画淡入淡出，与主卡片动画解耦：

```tsx
<motion.div
  initial={{ opacity: 0 }}
  animate={{ opacity: 1 }}
  exit={{ opacity: 0 }}
  className="absolute inset-0 bg-black/60 backdrop-blur-sm"
  onClick={onClose}
/>
```

**DOM 架构调整（变更后）**：

```
motion.div  [fixed inset-0 z-[1200]]  ← 整体容器（无 items-end，无 layoutId）
│
├── motion.div  [absolute inset-0 bg-black/60]  ← 背景遮罩（opacity 动画）
│
└── motion.div  [fixed inset-0 bg-background flex flex-col]  ← 主内容（x 平移动画）
    └── ... （与 §3 结构一致）
```
